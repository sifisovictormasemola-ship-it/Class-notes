# Class-notes

This repository is a structured collection of notes compiled throughout my learning journey in Data Analytics with SQL. The notes are organized by month, making it easy to follow my progress and revisit important concepts covered during each training period.

The repository serves as a personal knowledge base and study resource, covering theoretical concepts, practical examples, best practices, and key techniques learned in class. It is designed to reinforce my understanding while documenting my continuous growth in data analytics.


01 📂 Repository Structure

- **April Class Notes** – Topics and concepts covered during April.
- **May Class Notes** – Learning materials and exercises completed in May.
- **June Class Notes** – Notes, examples, and practical exercises from June.
- **July Class Notes** – Latest class notes, demonstrations, and learning activities.

02 🎯 Purpose

This repository was created to:
- Organize monthly class notes in one central location.
- Track my learning progress over time.
- Reinforce concepts through revision and practice.
- Build a well-documented study resource for future reference.
- Showcase my commitment to continuous learning and professional development in Data Analytics with SQL.
